## Scope summary

Add a Shiny Step 3 panel that shows four "did I use the instrument well?"
KPIs as semicircular gauges, with an instrument-type context header and a
one-line bottleneck summary footer. Derive-only — no new S3 fields, no
`PLOT_REGISTRY` entry, no PDF report change, no `stats.tsv` parsing.

The four KPIs:

1. **Filled window ratio** (%) — windows that contain ≥1 precursor.
2. **DPPP headroom** (×) — current DPPP median / target DPPP.
3. **Cycle time headroom** (%) — (required − actual) / required.
4. **Window count headroom** (%) — (max_windows − n_windows) / max_windows.
