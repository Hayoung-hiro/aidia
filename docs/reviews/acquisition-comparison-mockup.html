Evaluation data and assumptions

The method schedule defines geometric inclusion and isolation width. Co-isolation burden is a model using identified precursors and a stated elution interval; it is not measured fragment interference. The actual application will display the evaluation run, input filters, interval model, timing source, and whether the run was excluded from method design. No ID gain, CV improvement or sensitivity gain is inferred from these metrics.
