## 마무리 제안 — 아직 결정되지 않은 사항

1. FZ 기능 브랜치의 범위는 시각화로 마무리하고, 그룹 선택과 벤치마크는
   각각 별도 작업으로 진행한다. 원본 Projects 폴더나 브랜치를 삭제하지 않는다.
2. 다음 개발은 그룹 선택 설계 확정을 우선한다. 같은 입력 조건으로 전략을
   비교하려면, 서로 다른 method/sample의 전구체가 앞 단계에서 섞이지 않아야 한다.
3. 첫 구현은 선택한 한 조건을 먼저 필터링한 뒤 기존 consensus를 사용하는
   방향을 제안한다. 여러 그룹을 동시에 처리하는 확장은 별도 범위로 둔다.
4. 기본 그룹 키가 `method`이면 A/B sample이 함께 남을 수 있다. `sample`까지
   분리하도록 할지, 혼합 sample에서 CV 필터를 어떻게 처리할지 먼저 확정해야 한다.
   전부 0인 품질 열을 무조건 무시하는 정책도 실제 불량과 미제공을 구분해 정해야 한다.

벤치마크 착수 전 정리할 문서 불일치:

- 로드맵 P1.1은 장비별 FZ 적용을 제안하지만 후속 벤치마크 설계는 이를 철회한다.
- 벤치마크의 CSV 설명은 `22-column, z=0`으로 남아 있다. 현재 코드는 8열, 기본 z=1이다.
- FC 표는 `A vs B`라고 적었지만 계산식과 −1/+2 값은 B/A 방향이다.
  LFQb_Re 실제 대비 설정과 함께 맞춰야 한다.
- Parquet 어댑터의 부재는 가져온 문서에 기록된 상태다. 이번 작업에서는
  별도 LFQb_Re 저장소의 현재 구현 상태를 확인하지 않았다.

이 문서의 후속 제안은 논의용이며, 그룹 선택 기능이나 실험 설정 변경을 승인한 것으로
취급하지 않는다.
